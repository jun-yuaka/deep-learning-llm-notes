## 構成

```text
.
├── docs/study_guide.md   # 学習の進め方・Colab連携メモ
└── notebooks/            # Google Colab から保存したノートブック
```

## 著作権について

- 書籍の本文・図表・コードをそのまま転載しません。
- ここにあるのは、自分で書いた実装、検証、実験結果、学習メモのみです。
- 書籍の内容は、公式の書籍・公式リポジトリを参照してください。

## セキュリティ

- APIキーやトークンはコードやノートブックに書かず、Colab の「シークレット」機能や `.env`（gitignore 済み）で管理します。
- ノートブックを保存する前に、出力セルにキーが表示されていないか確認します。
