# 学習ガイド

## 進め方

1. 書籍の章を読み、概念を自分の言葉でまとめる
2. Colab で自分でコードを書いて動かす（写経だけで終わらせず、パラメータを変えて実験する）
3. 気づき・失敗・実験結果を `notebooks/` のノートブック内に Markdown で記録する
4. 章ごとにコミットする

## ノートブックの命名

`notebooks/chNN_topic.ipynb`（例: `ch03_tensors.ipynb`）

## Colab 連携メモ

- Colab で「ファイル → GitHub にコピーを保存」を選び、このリポジトリの `notebooks/` に保存する
- 初回は GitHub 連携の許可が必要
- APIキーは Colab の「シークレット」(左サイドバーの鍵アイコン) に保存し、コード内に直書きしない
- 保存前に出力セルを確認し、キーや個人情報が含まれていないことを確かめる
